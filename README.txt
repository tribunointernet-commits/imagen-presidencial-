1. Abrí index.html en el navegador para verla y probar los controles.
2. Para publicarla en GitHub Pages, subí index.html a la raíz de un repositorio público. En Settings → Pages, elegí Deploy from a branch / main / (root).
3. La URL pública normalmente es https://USUARIO.github.io/REPOSITORIO/ (reemplazar por datos reales).
4. El archivo iframe-ejemplo.html muestra cómo insertarla y hacer que ajuste su altura automáticamente.
5. Los datos están incluidos en index.html, dentro del arreglo presidents. No depende de librerías externas.

NOTA DE EDICIÓN: Antes de publicar, verificar cargos e identidades del cuadro original de CB Global Data. Esta visualización reproduce los nombres y las cifras de la imagen facilitada; no se realizó una auditoría de la condición actual de cada mandatario.
